# 室内视觉里程计双版本实战（`基础版v1` + `迭代版v2`）

用大白话来说，这个仓库只干一件事：**在没有 GPS 信号的室内，怎么只靠一个摄像头，让无人机或者你兜里的普通手机算出“我刚刚往哪儿走了多少米、转了多少度”？**

这套给摄像头装上“三维计步器”的技术就叫 **视觉里程计（Visual Odometry）**。为了把这个传感器从底层原理到日常实战彻底摸透，我们没有直接套用现成的黑盒 SLAM 框架，而是循序渐进做了两个版本，分别放在 **`基础版v1/`** 和 **`迭代版v2/`** 两个文件夹里。

---

## 为什么做两个版本？（它们各自干了啥）

### 1. `基础版v1` —— 拆开黑盒的手搓实验室版
很多教程一上来就调各种封装好的库，跑通了也不知道里面发生了什么。所以在 `基础版v1` 里，我们用带真实红外深度的室内数据集（TUM RGB-D），**核心模块全部自己手写**：
- **先给噪点画面“洗照片”**：自己搭了一个只有 **4.8 万参数**的 7 层轻量残差卷积网络（`ResidualCNN`，普通显卡跑 **2 分钟**就能从零训完）。它最聪明的地方是不去重画整张图，而是**专门把雪花噪点颗粒挑出来减掉**，所以书本和桌角边缘特别锐利。
- **再找角点算三维动作**：每帧抓 500 个 ORB 特征角点，正反双向核对防止认错，用自己写的 **3 点 RANSAC**（少数服从多数投票踢掉假匹配）加上 **SVD 点云刚体对齐**，一步步算出相机的三维轨迹。
- **踩出来的一个反直觉发现**：在满屏雪花重噪下，自训小网络确实能把快崩溃的特征匹配救回来；但在轻微噪点下，人眼看着更糊一点的 `7×7` 高斯平滑，总轨迹漂移居然比神经网络还略低几厘米——因为神经网络每帧聪明地修补边缘时，会让角点产生零点几个像素的微妙移动！**人眼觉得好看，真不一定等于几何定位最稳。**

---

### 2. `迭代版v2` —— 扔掉深度相机的日常手机实战版
真正的小型室内无人机根本背不动笨重的红外深度传感器，大家平时手里也只有普通单目手机。所以在 `迭代版v2` 里，我们**彻底扔掉了硬件深度相机**：
- **AI 一眼猜出真实“米数”**：接入零样本 **Depth Anything V2 米制深度模型**，只看一眼普通的彩色视频画面，不用偷看真值标定，直接预测出每个像素离镜头**有几米远**。
- **明暗 + 立体形状一起对齐**：用多尺度混合直接法（`Open3D Hybrid VO`），同时对齐前后两帧的“像素明暗”和“桌面/墙面立体几何”，横屏、竖屏手机视频都能跑（我们实拍的 3 段手机室内视频共 789 步，**100% 连续跟踪一步没丢**）。
- **实战踩出来的两个真相**：
  1. **千万别对暗光视频逐帧开“自动拉亮”！** 单帧自动拉对比度会让房间亮度像坏掉的灯泡一样忽明忽暗，直接把 AI 对房间大小的判断骗懵，轨迹误差暴增 19 倍（飙到 `3.85 米`）；给运动模糊强行做锐化也会造出一圈假白边帮倒忙。
  2. **为什么对着衣柜门笔直往前走、往后退，原始 3D 轨迹却像小锯齿？** 拆开数据发现大方向其实 100% 准（前进 `+0.85 米`、后退 `-0.57 米`）；之所以有小锯齿，是因为手机每秒拍 **30 帧**，人走一步拆到每一帧只前进了 **0.6 厘米（不到半个指甲盖）**，而单帧 AI 猜深度每帧会有 **±2~3 厘米**的“微呼吸”抖动——只要这帧把门猜远了 2 厘米，算法就以为你偷偷倒退了 2 厘米！只要加上短窗口滤波，顺滑的一进一退立刻就显形了。

## 怎么快速玩起来？（三种方式任选）

### 方式一：零环境配置，直接看 3D 交互可视化界面（最推荐！）
哪怕你电脑上还没装深度学习环境，也能直接体验跑好的全部结果：
1. 直接用浏览器打开 **`迭代版v2/demo/index.html`**（或者双击 `迭代版v2/启动离线演示.bat`）。
2. 在网页里你可以：
   - 点击 **`⬆ 上传视频 (.mp4)`** 导入视频或一键切换三段手机实拍视频、TUM 基准和暗光/模糊消融实验；
   - 切到视频流页面，同步播放左边的 **AI 米制深度热力图** 和右边的 **三维轨迹动态生长过程**；
   - 在主界面的 3D 视窗里，**滚动鼠标滚轮缩放大小、按住左键拖拽自由旋转移动视角**（也可以点右侧 `+ / - / 3D / XY / XZ` 按钮切换视角），右上角还能一键切换中英文界面。
3. 同理，打开 **`基础版v1/demo/index.html`**（或双击 `基础版v1/启动方案F可视化.bat`）可以查看基础版在不同噪点强度下的去噪细节、特征点匹配连线和轨迹对比。

---

### 方式二：拿一段你自己手机拍的视频跑 `迭代版v2`
如果你想喂一段自己手机拍的室内 `.mp4` 视频进去算出三维轨迹：

1. **装好环境**（建议 Python 3.10+，带 NVIDIA 显卡跑得更快）：
   ```bash
   cd 迭代版v2
   pip install -r requirements-lock.txt
   ```
   *(首次运行时会自动拉取 `Depth Anything V2 Metric Hypersim Small` 室内米制深度权重，也可以放到本地 `models/` 目录离线加载。)*

2. **第一步：让 AI 把普通视频转成“米制深度图”**：
   ```bash
   python src/video_depth.py \
       --video inputs_phone_videos/phone_video_02_forward_portrait_139f.mp4 \
       --output results/my_phone_depth \
       --resize-width 540
   ```

3. **第二步：算出每一帧怎么走，生成三维轨迹和回放视频**：
   ```bash
   python src/predicted_rgbd_vo.py \
       --depth-dir results/my_phone_depth \
       --intrinsics calibration/estimated_intrinsics_540x960.json \
       --output results/my_phone_vo \
       --tracking-width 360
   ```
   跑完后去 `results/my_phone_vo/` 就能拿到完整三维坐标 `trajectory.txt`、轨迹图和动态回放 MP4！

### 方式三：从头体验 `基础版v1`（2 分钟训完去噪网络 + 跑手写里程计）

```bash
cd 基础版v1
pip install -r requirements-core.txt

# 1. 跑一遍传统 7x7 可分离高斯滤波基线
python scripts/run_step03_gaussian_baseline.py

# 2. 从零训练 7 层轻量残差去噪网络（10,000 步，RTX 3060 约 2 分钟）
python scripts/run_step07_formal_train.py

# 3. 联合跑完图像去噪 + 手写 ORB/RANSAC/SVD 视觉里程计全套评测
python scripts/run_step08_joint_eval.py
```
*(注：如果要重跑完整训练和 TUM 原始序列评测，把公开的 BSDS300 和 TUM `freiburg1_xyz` / `freiburg3_structure_texture_far` 数据集解压到 `configs/` 里对应的路径即可；若只想直接加载我们训好的模型，权重已经放在 `checkpoints/best_step6000.pt` 里了。)*
